PULSEFALL

비트 위에서만 벽이 열린다.

장르 리듬 반사 아케이드 플랫폼 웹 (데스크톱 · 모바일 브라우저) 팀 김범수 · 송채우 · 신승민 제출일 2026. 08. 10

01한 줄 소개

벽을 피하는 게임이 아니라, 벽에 얼마나 가까이 붙어 있었는지로 점수가 나는 게임. 안전하게 지나가면 0점이고, 스칠수록 뜨거워지며, 틈이 없는 벽은 오직 박자 위에서만 뚫린다.

핵심 한 문장

리듬 게임은 보통 "정확히 눌렀는가"를 묻습니다. PULSEFALL은 "위험한 곳에 머물 배짱이 있었는가"를 묻습니다. 안전지대로 도망치는 순간 점수가 멈추기 때문에, 살아남는 것과 잘하는 것이 정반대 방향입니다.

03목표 · 종료 조건

목표

곡이 끝날 때까지 살아남아 진행도 100%를 찍는 것. 다만 클리어는 최저 기준일 뿐이고, 실제로 겨루는 것은 점수입니다.

점수 = 생존한 시간 × HEAT 배율

HEAT는 벽을 스칠 때만 오르고, 아무것도 안 하면 서서히 식습니다. 최대 ×8까지 오릅니다.

종료 조건

  • 사망 — 커서가 벽에 닿는 즉시. 라이프 없음, 체력 없음, 한 번에 끝.
  • 클리어 — 곡의 마지막 마디를 통과.
  • ENDLESS — 종료 조건 없음. 죽을 때까지.

죽으면 결과 화면에서 SPACE 한 번으로 즉시 재시작합니다. 실패를 전제로 만든 게임이라, 죽음과 다음 시도 사이의 거리를 가장 짧게 뒀습니다.

조작 설계 원칙

커서는 절대 터치한 위치로 순간이동하지 않습니다. 누르고 있는 동안에만 일정 속도로 돕니다. 순간이동을 허용하면 모든 벽이 "누를 수 있느냐"의 문제로 바뀌어, 미리 읽고 미리 가 있는 플레이가 무의미해집니다. 이동 속도가 고정이기 때문에 도달 가능성이라는 개념이 성립하고, 그 위에서 차트의 공정성을 수학적으로 보장할 수 있습니다. (→ AI 활용 기술 문서 §4)

05규칙 — 60초면 충분합니다

① GRAZE — 스칠수록 강해진다

벽 가장자리를 아슬아슬하게 지나가면 게이지와 HEAT가 오릅니다. 한가운데 넓은 틈으로 안전하게 지나가면 아무것도 얻지 못합니다. 이것이 이 게임의 유일한 자원 획득 수단입니다.

② PULSE — 박자 위에서는 공짜다

0.26초 동안 벽을 통과합니다. 평소에는 게이지 한 칸을 통째로 씁니다. 그러나 비트에 맞추면 0.32칸만 쓰고, 게이지가 비어 있어도 무조건 발동합니다.

이 게임의 중심 규칙

"박자 위의 PULSE는 절대 거부되지 않는다"는 규칙이 SEAL을 공정하게 만드는 유일한 근거입니다. 게이지가 없어도 비트만 맞으면 뚫리기 때문에, 플레이어는 어떤 상황에서도 이론적으로 살아남을 수 있습니다. 게임 코드·차트 검증기·오토플레이 봇 세 곳이 전부 이 규칙 하나를 공유합니다.

③ SEAL — 피할 수 없는 링

틈이 아예 없는 벽입니다. 색이 달라서 미리 보입니다. 좌우로 도망칠 방법이 없고, PULSE만이 답입니다. 리듬을 놓치면 그대로 죽습니다.

④ SWIRL — 지금 보이는 틈은 진짜 틈이 아니다

벽이 회전하면서 다가옵니다. 현재 틈이 있는 방향으로 달려가면 도착했을 때는 벽입니다. 도착할 자리를 읽고 먼저 가 있어야 합니다. 벽은 플레이어에게 닿는 순간 정확히 회전을 멈춥니다.

⑤ 카메라 — 어려워질수록 기울어진다

게임 화면은 정직한 2D 원반(7°)에서 시작해, 구간 난이도·진행도·HEAT에 따라 최대 45°까지 기울어집니다. 45°는 넘을 수 없는 상한입니다. 투영은 원근이 아닌 축측(axonometric)이라, 아무리 기울어도 먼 쪽 레인과 코앞 레인의 틈 폭이 정확히 같습니다 — 연출이 판정을 침범하지 않습니다.

07실행 방법

A. 브라우저에서 바로 실행 (심사용 권장)

아래 링크를 클릭하면 끝입니다. 설치·계정·결제·유료 라이선스가 전혀 없습니다. 

https://aiswkimbeomsu.github.io/pulsefall/
  • 권장 브라우저 — Chrome · Edge · Safari 최신 버전 (데스크톱 / 모바일 모두 동작)

B. 로컬에서 소스로 실행

# Node.js 18 이상. 설치할 의존성이 없습니다.
git clone https://github.com/AISWKimBeomSu/pulsefall.git
cd pulsefall
node server.js          # → http://127.0.0.1:4173

같은 Wi-Fi의 스마트폰에서 확인하려면 터미널에 출력되는 Same Wi-Fi: 주소를 사용하세요.

node scripts/smoke_test.mjs   # 79개 검사 — 오토플레이 봇이 전 차트 100% 클리어

08기술 요약

0외부 의존성
0외부 에셋 파일
240Hz고정 시뮬레이션
79자동 검사
  • 순수 ES 모듈 + Canvas 2D + Web Audio API. 빌드 도구도, 프레임워크도, 번들러도 없습니다. 저장소를 그대로 정적 호스팅하면 그것이 곧 배포본입니다.
  • 이미지·사운드 파일이 한 개도 없습니다. 그래픽은 전부 코드로 그리고, 음악은 브라우저에서 실시간 합성됩니다. 총 전송량은 아이콘 포함 수백 KB 수준입니다.
  • 시뮬레이션 240Hz 고정 틱을 렌더 프레임과 분리했습니다. 60Hz든 120Hz든 재생 결과가 같습니다.
  • 적응형 품질 — 프레임 예산이 새기 시작하면 플레이어가 느끼기 전에 렌더 품질을 먼저 낮춥니다.
  • 측정치 — 60fps 고정, 프레임 0.5ms, 최악 0.8ms (M-시리즈 맥, 데스크톱 뷰포트).
