# PULSEFALL

> 비트 위에서만 벽이 열린다.

**▶ 지금 플레이 — https://aiswkimbeomsu.github.io/pulsefall/**

벽을 피하는 게임이 아니라, 벽에 얼마나 가까이 붙어 있었는지로 점수가 나는 리듬 반사 아케이드.
안전하게 지나가면 0점이고, 스칠수록 뜨거워지며, 틈이 없는 벽은 오직 박자 위에서만 뚫립니다.

빌드 도구 없는 순수 ES 모듈 + Canvas 2D + Web Audio. **의존성 0개, 외부 에셋 0개.**

## 실행

브라우저에서 [링크](https://aiswkimbeomsu.github.io/pulsefall/)를 여는 것으로 끝입니다.
설치·계정·결제·유료 라이선스가 없습니다. **소리를 켜고 플레이하세요** — 음악이 곧 판정 정보입니다.

로컬에서 소스로 돌리려면:

```bash
node server.js
```

`http://127.0.0.1:4173` 을 엽니다. `npm install` 이 필요 없습니다 — 설치할 의존성이 없습니다.
같은 Wi-Fi의 폰에서 테스트하려면 터미널에 찍히는 `Same Wi-Fi:` 주소를 쓰세요.

## 조작

|  | 이동 | PULSE |
|---|---|---|
| 키보드 | `←` `→` / `A` `D` | `Space` `↑` `↓` `Shift` |
| 마우스 | 좌클릭 / 우클릭 (누르고 있기) | 휠 클릭 |
| 터치 | 화면 좌측 / 우측 끝 | 화면 **중앙** 세로 띠 |
| 게임패드 | 스틱 / D패드 | A · B · R1 · R2 |

`Esc` 일시정지 · 결과 화면에서 `Space` 재시작 · **`R` 플레이 녹화**

> 커서는 **절대 터치한 위치로 순간이동하지 않습니다.** 누르고 있는 동안만 돕니다.
> 이동 속도가 고정이라야 "도달 가능성"이 정의되고, 그 위에서 차트 공정성을 증명할 수 있습니다.

## 규칙

- **GRAZE** — 벽 가장자리를 스치면 게이지와 HEAT가 오릅니다. **점수 = 시간 × HEAT.**
  안전하게 한가운데로 지나가면 아무것도 못 얻습니다.
- **PULSE** — 0.26초 무적. 게이지 1칸.
  **박자에 맞추면 0.32칸이고, 게이지가 없어도 발동합니다.**
- **SEAL** — 틈이 없는 링(다른 색). 피할 수 없습니다. 비트에 맞춰 뚫으세요.
- **SWIRL** — 벽이 돌면서 옵니다. 지금 보이는 틈은 진짜 틈이 아닙니다.
- 벽은 비트에 **도착**합니다. 차트는 고정입니다. 죽은 자리는 외울 수 있습니다.

## 검증

```bash
node scripts/smoke_test.mjs   # 79개 검사 — 오토플레이 봇이 전 차트 100% 클리어
node scripts/audit.mjs all    # 렌더 비용·금지 API 감사
```

차트는 절차 생성되지만 **불가능한 배치는 컴파일 타임에 제거**됩니다. 컴파일러가 벽을 도착 시각
기준 링으로 묶고, 플레이어의 실제 각속도로 도달 가능성을 계산해 닿을 수 없는 링을 격자 위에서
회전시킵니다. 그리고 헤드리스 오토플레이 봇이 CI에서 매번 전곡을 실제로 플레이합니다 —
**하나라도 100%를 못 찍으면 배포가 막힙니다.**

## 플레이 녹화

게임 안에서 `R` 키를 누르면 녹화가 시작되고, 다시 누르면 `.webm` 파일이 내려받아집니다.
캔버스 백버퍼와 오디오 그래프를 직접 캡처하므로 **편집·합성 없이 실제 플레이 화면 그대로**이며,
화면 녹화와 달리 프레임을 잃지 않고 마우스 커서나 주소창이 찍히지 않습니다.

YouTube 업로드용 mp4가 필요하면:

```bash
ffmpeg -i pulsefall-*.webm -c:v libx264 -crf 18 -preset slow -c:a aac -b:a 192k -movflags +faststart play.mp4
```
